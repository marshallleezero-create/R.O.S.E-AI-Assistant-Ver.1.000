## 🚀 Quick Commands

```bash
# Setup & run ROSE
python setup_wizard.py
uvicorn main:app --reload

# View documentation locally
pip install mkdocs mkdocs-material
mkdocs serve
# Open http://localhost:8000

# Build static docs
mkdocs build
```
